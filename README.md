# 나만의 퀴즈 게임

## 프로젝트 개요

터미널에서 실행하는 Python 콘솔 퀴즈 게임입니다.
메뉴에서 번호를 골라 퀴즈를 풀거나, 새 퀴즈를 추가하거나, 목록과 최고 점수를 확인할 수 있습니다.
퀴즈와 최고 점수는 `state.json` 파일에 저장되어, 프로그램을 종료했다가 다시 실행해도 그대로 유지됩니다.

- 언어: Python 3.10 이상 (외부 라이브러리 없이 표준 라이브러리만 사용)
- 구조: `Quiz`(퀴즈 한 문제), `QuizGame`(게임 전체 관리) 두 클래스로 역할 분리

## 퀴즈 주제와 선정 이유

**주제: 파이썬 기초**

이 미션에서 배우는 Python 기본 문법(자료형, 조건문, 반복문, 리스트와 딕셔너리)을
직접 퀴즈로 만들어 보면서 다시 정리하고, 다른 사람도 풀며 복습할 수 있게 하려고 선택했습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있는지 확인합니다.
   ```
   python --version
   ```
2. 저장소를 내려받고 폴더로 이동합니다.
   ```
   git clone https://github.com/leesw0224/quiz-game.git
   cd quiz-game
   ```
3. 프로그램을 실행합니다.
   ```
   python main.py
   ```

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 등록된 퀴즈를 순서대로 출제하고, 정답/오답과 최종 점수(100점 만점)를 보여줍니다. 최고 점수를 넘으면 기록을 갱신합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 새 퀴즈를 등록하고 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 문제 목록을 번호와 함께 보여줍니다. |
| 4 | 점수 확인 | 최고 점수와 그때의 정답 수를 보여줍니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 종료합니다. |

**입력 및 예외 처리**

- 숫자 입력의 앞뒤 공백은 제거한 뒤 처리합니다.
- 숫자가 아닌 입력, 허용 범위 밖의 숫자, 빈 입력은 안내 메시지를 보여주고 다시 입력받습니다.
- 퀴즈가 없거나 아직 퀴즈를 풀지 않은 경우에도 안내 메시지를 보여줍니다.
- `Ctrl+C`나 입력 종료(EOF)가 발생해도 오류로 멈추지 않고, 데이터를 저장한 뒤 안전하게 종료합니다.

## 파일 구조

```
quiz-game/
├── main.py       # 프로그램 전체 (Quiz, QuizGame 클래스와 입력 처리 함수)
├── README.md     # 프로젝트 설명
├── .gitignore    # Git에서 제외할 파일 목록
└── state.json    # 실행 시 자동 생성되는 데이터 파일 (Git에서 제외)
```

**main.py 구성**

| 구분 | 이름 | 역할 |
|---|---|---|
| 클래스 | `Quiz` | 퀴즈 한 문제 (문제 출력, 정답 확인, 딕셔너리 변환) |
| 클래스 | `QuizGame` | 게임 전체 (메뉴, 풀기, 추가, 목록, 점수, 저장/불러오기) |
| 함수 | `get_default_quizzes()` | 기본 퀴즈 6개 생성 |
| 함수 | `input_number()`, `input_text()` | 숫자·글자 입력 검증 |

## 데이터 파일 설명 (state.json)

- **경로:** 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더)
- **역할:** 퀴즈 목록과 최고 점수를 저장해서, 프로그램을 다시 실행해도 데이터가 유지되게 합니다.
- **인코딩:** UTF-8
- **저장 시점:** 퀴즈 추가 후, 최고 점수 갱신 후, 종료할 때 (`Ctrl+C` 포함)

**스키마**

```json
{
  "quizzes": [
    {
      "question": "Python에서 정수(integer)를 나타내는 자료형은?",
      "choices": ["int", "str", "bool", "list"],
      "answer": 1
    }
  ],
  "best_score": 100,
  "best_correct": 6,
  "best_total": 6
}
```

| 키 | 형식 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 |
| `question` | 문자열 | 문제 |
| `choices` | 문자열 4개 리스트 | 선택지 |
| `answer` | 정수 (1~4) | 정답 번호 |
| `best_score` | 정수 (0~100) 또는 `null` | 최고 점수 (100점 만점 환산), 기록이 없으면 `null` |
| `best_correct` | 정수 또는 `null` | 최고 점수일 때 맞힌 문제 수 |
| `best_total` | 정수 또는 `null` | 최고 점수일 때 전체 문제 수 |

**파일이 없거나 손상된 경우**

- 파일이 없으면(첫 실행) 기본 퀴즈 6개로 시작합니다.
- JSON 형식이 깨졌거나 값이 잘못된 경우(예: 선택지가 4개가 아님, 정답이 1~4가 아님) 안내 메시지를 보여주고 기본 퀴즈로 복구합니다.

**Git에서 제외한 이유**

`state.json`은 실행할 때마다 내용이 바뀌는 사용자 데이터라 `.gitignore`에 넣어 저장소에서 제외했습니다.
기본 퀴즈는 코드(`get_default_quizzes()`)에 들어 있어서, 파일이 없어도 프로그램이 정상 동작합니다.- Git clone 및 pull 실습을 통해 원격 저장소와 로컬 저장소의 동기화를 확인했습니다.
- 두 번째 작업 폴더에서 git pull 동기화 실습을 진행합니다.
